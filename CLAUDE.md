# Instructions for Claude Code

Read HANDOFF.md, PROJECT_CONTEXT.md, PROGRESS.md and NEXT_STEPS.md before making changes.

## Project layout
- client/ is the React (Vite) frontend
- server/ is the Express and Mongoose backend

## Rules
- Run git status before editing. Do not overwrite existing work.
- Never read, print or commit .env files or secrets. Use .env.example for variable names.
- Keep code simple and readable. Use clear names, avoid over-engineering and avoid comments that repeat the code.
- Explain important changes in plain language, because the student must explain them in a viva.
- Make small, meaningful commits with descriptive messages.
- Do not mark a feature complete until it has been tested (API in Postman, UI in the browser).
- After each major task update PROGRESS.md and NEXT_STEPS.md.
