# Airbnb Clone (MERN)

A full-stack accommodation booking web application built with MongoDB, Express, React and Node.js. Users can list properties, search for places to stay, book dates and manage their bookings. This is my B.Tech CSE capstone project (Module 8).

The project is inspired by Airbnb's usability, but uses its own branding and design.

## Features (planned)

- User registration and login with JWT
- Create, edit and delete property listings with multiple images
- Search by location, filter by price, property type, guests and dates
- Booking with availability check and overlap prevention
- User dashboard for bookings, listings and account details
- Responsive layout for mobile, tablet and desktop

## Tech stack

- Frontend: React (Vite), React Router, Axios, Tailwind CSS
- Backend: Node.js, Express, MongoDB (Atlas), Mongoose
- Other: JWT, bcrypt, Multer, Cloudinary, dotenv, Postman

## Project structure

    client/   React frontend
    server/   Express backend and API
